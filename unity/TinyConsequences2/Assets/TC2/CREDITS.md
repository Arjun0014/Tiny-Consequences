the project owner). Requests for assets that need a human (download, purchase, licence) are in

  (Copyright (C) 1993 Sun Microsystems; "Permission to use, copy, modify, and distribute this software is freely
  granted, provided that this notice is preserved").
- SplitMix64 mixing constants (Steele, Lea, Flood 2014; public domain reference implementation by Sebastiano Vigna).

## Assets
- Every mesh, texture and shader is generated by this project's code (`Game/View/ProcMeshes.cs`, `Game/Resources/TC2Shaders/`).
- **The world's sound** (`Game/Resources/Audio/`, 71 Ogg Vorbis files: 16 ambient beds, the action and creature sounds in two or three takes, 5
  interface cues; F10.1, session 25): generated for this project (Tiny Consequences 1, session 21, `assets/audio/manifest.json`) with the ElevenLabs
  sound effects model (`eleven_text_to_sound_v2`) on the project owner's ElevenLabs account, levelled and encoded with ffmpeg; no third-party
  recordings. Use is subject to that account's ElevenLabs terms - commercial use needs a paid plan: check before publishing commercially.
