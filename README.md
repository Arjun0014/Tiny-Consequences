# Tiny Consequences

A cute tiny planet that lives on its own. You're its god. Poke it, speed up time, and watch one small act ripple through decades or millennia, with every consequence traced back to Nature or to You.

Entry for the **Defold Game Jam 2026** (theme: Chain Reaction). Built with Defold; the simulation is pure Lua and testable headless.

- Start here (human): `SETUP_HUMAN.md`
- Start here (Claude Code): `CLAUDE.md`
- Design: `docs/01_VISION.md` → `docs/08_ROADMAP.md`
- Status: `docs/PROGRESS.md`

Quick commands (after Stage 1.1): `npm run setup`, `npm run play`, `npm run test:sim`, `npm run test:web`.
