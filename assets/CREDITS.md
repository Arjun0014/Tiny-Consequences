## Generated (original) assets

- UI panels and icons in `ui/` — generated by `scripts/gen_ui.py` (original art).
- Props, trees, houses, clouds, animals — generated procedurally at runtime (`game/view/propgen.lua`).
- `textures/white4.png` — placeholder texture generated by script.
